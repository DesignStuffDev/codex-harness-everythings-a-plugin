# Unadopted Ephemeral auth primitive proposal

This source-only archive preserves the private revision/ticket primitive, eight proposed tests, exact preimages and its design/review notes. It is not formatted, compiled, tested or activated in the host. Complete manager/writer integration remains required; this is neither a completed auth component nor a transaction guarantee for File, Keyring or Auto.

The archived draft's phrase “compiled private code” describes its intended form, not observed compilation. No compiler or test ran on this proposal.

Every archived member was read back and matched its source bytes. The archive is initially VM-local; external durability requires verified publication. No executable, cache, runtime credential or installed configuration is included.
